# Fusion Pixel Font

- 作者：TakWolf 及字体上游贡献者。
- 官方仓库：https://github.com/TakWolf/fusion-pixel-font
- 固定版本：2026.10.25。
- 页面字体：12px Proportional，zh-Hans 版本（包含中文、日文假名和拉丁字符）。
- 代码字体：12px Monospaced，zh-Hans 版本。
- 文件保持原始名称与内容；未修改、未子集化。
- 下载来源：官方 Releases 的 `12px-proportional-otf.woff2` 与 `12px-monospaced-otf.woff2` 压缩包。
- 许可：SIL Open Font License 1.1，见同目录 `OFL.txt`；上游授权见 `LICENSES/`。

字体从本站本地加载，使用 `font-display: swap`；界面以 12px 为主要字号，标题使用 24/36/48px，正文采用较大字号和行距以便阅读。
