这道题在统计岛屿数量的基础上，多了一个总价值的条件：只有整座岛屿的价值之和能被 k 整除，才计入答案。我的做法是用 DFS 找到每个四方向连通的陆地区域，在遍历过程中累加价值，最后统一判断。

## 先找到一整座岛屿，再判断价值

网格中，0 表示水域，正整数表示陆地。只有上下左右相邻的陆地相连，对角线接触不算连通。

因此，不能对每个格子的值单独取余，也不能统计陆地格子数量后判断。需要先把同一座岛屿上的所有值加起来：

```text
岛屿总价值 = 该连通区域内所有陆地格子的数值之和

总价值 % k == 0
    → 这座岛屿计入答案
```

例如两个相连的格子分别为 2、3，k = 5 时，两格单独都不能被 5 整除，但整座岛屿的总价值为 5，应该计入。

## 用 map 记录访问状态

代码创建了与 grid 同样大小的布尔矩阵 map。这里的 map 是变量名，实际类型为 vector<vector<bool>>，用来标记格子是否已经访问。

外层双重循环检查每一个位置，只有同时满足下面两个条件时，才启动一次新的 DFS：

- 当前值不为 0，是陆地。
- 当前格子没有访问过。

DFS 会一次性标记这座岛屿上的全部陆地。因此，之后外层循环再遇到同一岛屿的其他格子时，就会直接跳过，不会重复统计。

本题网格值非负，所以代码中的“不等于 0”与“是正整数陆地”在这里等价。

## loop 如何遍历四个方向

每次进入 loop，先做两件事：

```cpp
map[i_n][j_n] = true;
sum += grid[i_n][j_n];
```

随后依次检查上、下、左、右四个邻居。只有没有越界、仍然是陆地、而且尚未访问时，才递归进入。

访问标记必须在探索邻居之前设置。否则相邻两个格子可能互相递归回去，也可能让同一格子的价值重复加入总和。

方向检查中的顺序也有意义：先确认坐标合法，再读取 grid 和 map，利用逻辑与的短路行为避免越界访问。

## 为什么 sum 要通过引用传递

loop 的最后一个参数是 long int& sum。所有递归调用操作的是同一个累加器，每访问一个新的陆地格子，就把它的价值加进去。

外层每发现一座新岛屿，都会先创建 sum = 0，再调用 DFS。这样岛屿之间的价值不会混在一起。

当该次 DFS 返回时，整座岛屿都已经访问完毕，此时再判断 sum % k 是否为 0。取余检查每座岛只做一次，而不是在递归途中看到某个中间和满足条件就增加答案。

## 用一个网格走一遍

令 k = 5，网格如下：

```text
2  3  0
0  0  4
6  0  1
```

| 岛屿 | 包含的格子值 | 总价值 | 是否计入 |
| --- | --- | ---: | --- |
| 第一座 | 2、3 | 5 | 是 |
| 第二座 | 4、1 | 5 | 是 |
| 第三座 | 6 | 6 | 否 |

第一座岛屿中的 3 与第二座中的 4 只在对角线方向接近，因此不会连成一座岛。最终答案为 2。

遍历第一座岛后，2、3 对应的访问标记都变为 true。外层循环继续遇到 3 时，会直接跳过；4、1 与 6 则分别触发各自岛屿的 DFS。

## C++ 实现

下面保留原代码：

```cpp
class Solution {
public:
    int loop(vector<vector<int>>& grid, vector<vector<bool>>& map, int i_n, int j_n, int m, int n, long int& sum) {
        map[i_n][j_n] = true;
        sum += grid[i_n][j_n];
        if (i_n - 1 >= 0 && grid[i_n - 1][j_n] != 0 && !map[i_n - 1][j_n]) {
            loop(grid, map, i_n - 1, j_n, m, n, sum);
        }
        if (i_n + 1 < m && grid[i_n + 1][j_n] != 0 && !map[i_n + 1][j_n]) {
            loop(grid, map, i_n + 1, j_n, m, n, sum);
        }
        if (j_n - 1 >= 0 && grid[i_n][j_n - 1] != 0 && !map[i_n][j_n - 1]) {
            loop(grid, map, i_n, j_n - 1, m, n, sum);
        }
        if (j_n + 1 < n && grid[i_n][j_n + 1] != 0 && !map[i_n][j_n + 1]) {
            loop(grid, map, i_n, j_n + 1, m, n, sum);
        }
        return sum;
    }

    int countIslands(vector<vector<int>>& grid, int k) {
        int m = grid.size();
        int n = grid[0].size();
        int answer = 0;
        vector<vector<bool>> map(m, vector<bool>(n, false));
        for (int i = 0; i < m; i++) {
            for (int j = 0; j < n; j++) {
                if (grid[i][j] != 0 && !map[i][j]) {
                    long int sum = 0;
                    loop(grid, map, i, j, m, n, sum);
                    cout << sum << endl;
                    if (sum % k == 0) {
                        answer++;
                    }
                }
            }
        }
        return answer;
    }
};
```

## 实现中值得注意的细节

sum 的更新依靠引用，主函数没有使用 loop 的返回值。辅助函数可以改成 void，让接口更直接；这里仍保留原代码的 int 返回类型。

总价值可能很大，累加类型需要足够宽。long int 的宽度取决于编译平台，不能仅凭类型名称就认为一定是 64 位。若整理成通用版本，建议把累加器统一改为 long long，并将辅助函数改为 void，避免返回总和时再转换成 int。当前原代码中的返回值虽然没有参与统计，返回类型仍与累加器类型不一致。

cout 输出的是每座岛的总价值，用于调试观察，不参与答案计算。正式使用时可以去掉，避免额外输出和频繁刷新带来的开销。

递归深度也取决于岛屿形状。陆地连成很长的路径时，调用栈可能较深；若运行环境栈空间不足，可以用显式栈实现 DFS，或改成队列 BFS，遍历与求和思路不变。

## 正确性说明

从一块未访问的陆地出发，DFS 只沿四个方向进入未访问陆地，因此不会越过水域或跨到不连通区域。同时，任何与起点连通的陆地，都能沿某条陆地路径被发现，所以这次 DFS 恰好覆盖一整座岛屿。

每个格子进入 DFS 后立刻标记，之后不会再次加入总和。因此，遍历结束时 sum 恰好等于这座岛屿所有格子的价值之和。

外层循环最终会发现所有岛屿，并且每座只触发一次新的 DFS。对每个完整总和判断能否被 k 整除，恰好得到题目要求的岛屿数量。

## 复杂度分析

- 时间复杂度为 O(m × n)：外层遍历全部格子，每个陆地格子最多访问一次，每次只检查四个方向。
- 辅助空间复杂度为 O(m × n)：访问矩阵占用与网格大小成正比的空间；递归调用栈在最坏情况下也可能达到 O(m × n)。

这类题可以先把“找到连通区域”与“区域满足什么条件”分开。DFS 负责枚举一整块区域，累加器记录该区域的信息，区域遍历结束后再做最终判断。
