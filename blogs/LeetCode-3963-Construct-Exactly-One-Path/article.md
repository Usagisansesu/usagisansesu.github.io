题目要求构造一个 m × n 的网格，其中点号表示空单元格，井号表示障碍物。从左上角出发，每次只能向右或向下移动，最终到达右下角，并且有效路径必须恰好只有一条。

我的做法是先把整个网格填成障碍，再沿着第一行和最后一列打通一条折线路径。这样既能保证起点与终点连通，也能避免出现额外的路线。

## 核心思路：只留一条可以走的路

这是一道构造题，不需要先建立复杂的网格，再计算其中有多少条路径。题目允许返回任意满足条件的结果，因此可以直接设计一个没有分岔的网格。

我选择的路线是：

```text
(0, 0)
    → 沿第一行一直向右
(0, n - 1)
    → 沿最后一列一直向下
(m - 1, n - 1)
```

除这条路线以外，其余位置全部设置为障碍。

## 代码如何完成构造

首先创建 m 行、每行 n 个字符的结果，将所有位置初始化为井号：

```cpp
vector<string> answer(m, string(n, '#'));
```

第一个循环遍历行下标，把每一行的最后一个字符改成点号，也就是打通最后一列：

```cpp
for (int i = 0; i < m; i++) {
    answer[i][n - 1] = '.';
}
```

第二个循环遍历列下标，把第一行全部改成点号：

```cpp
for (int i = 0; i < n; i++) {
    answer[0][i] = '.';
}
```

注意，构造时先修改最后一列，再修改第一行，不影响最终行走的顺序。右上角会被两个循环各赋值一次，但两次写入的都是点号，不会产生冲突。

## 用一个例子走一遍

假设 m = 4、n = 5，最终得到：

```text
.....
####.
####.
####.
```

从左上角出发，在到达最后一列之前，下方都是障碍，所以只能向右。走到右上角后，右侧已经越界，只能沿最后一列向下，直到终点。

整条有效路径经过 m + n - 1 个空单元格，需要移动 m + n - 2 步。这里右上角同时属于第一行和最后一列，统计格子时只算一次。

## C++ 实现

下面保留我的原代码：

```cpp
class Solution {
public:
    vector<string> createGrid(int m, int n) {
        vector<string> answer(m, string(n, '#'));
        for (int i = 0; i < m; i++) {
            answer[i][n - 1] = '.';
        }
        for (int i = 0; i < n; i++) {
            answer[0][i] = '.';
        }
        return answer;
    }
};
```

## 为什么恰好只有一条路径

先看路径是否存在。第一行和最后一列都是空单元格，它们在右上角相交。因此，先沿第一行向右，再沿最后一列向下，就能从起点到达终点。

再看是否可能出现第二条路径。对于第一行中还没有到达最后一列的位置，只要下方仍在网格内，下方就是障碍，不能提前向下。进入最后一列后，又无法继续向右，只能向下。每一步的合法前进方向都被唯一确定，所以不存在其他有效路线。

结合存在性和唯一性，这个构造恰好满足题目要求。

## 单行、单列也可以直接处理

- 当 m = 1 时，整张网格只有第一行，唯一的路径就是一直向右。
- 当 n = 1 时，整张网格只有最后一列，唯一的路径就是一直向下。
- 当 m = 1 且 n = 1 时，唯一的格子为点号，起点就是终点，不需要移动，也恰好有一条路径。

这些情况都由原代码自然覆盖，不需要额外分支。

## 复杂度分析

- 时间复杂度为 O(m × n)：初始化整个结果需要写入 m × n 个字符，后续两个循环共进行 m + n 次赋值。不能只看这两个循环，就把整体时间算成 O(m + n)。
- 空间复杂度为 O(m × n)：返回的网格占用与格子数相同数量级的空间；除返回结果外，只使用循环变量，辅助空间为 O(1)。

这道题的关键是利用“任意一个符合条件的网格”这一要求。主动把所有分岔封住，就能直接保证路径唯一，不必再用动态规划统计路径数量。
