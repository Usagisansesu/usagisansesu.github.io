这道题每次可以把一个连续子字符串排序，但不能选择整个字符串。我的代码没有真的执行排序，而是统计前后缀的最小字符、最大字符与有序状态，再根据首尾边界直接判断最少操作次数。

## 先处理长度为 1 和 2 的情况

长度为 1 时，字符串天然有序，答案为 0。

长度为 2 时，合法的非空真子串都只有一个字符，排序不会改变字符串。因此，两个字符本来有序就返回 0，否则返回 -1。

长度至少为 3 时，前 n − 1 个字符和后 n − 1 个字符都可以作为合法操作区间，后面的分类讨论就围绕它们展开。

## 为什么统计 s1 和 s2

代码建立了两个长度为 n − 1 的字符串：

```text
s1 = s[0 .. n-2]：去掉最后一个字符的前缀
s2 = s[1 .. n-1]：去掉第一个字符的后缀
```

它们分别对应“固定最后一个字符，整理前面”和“固定第一个字符，整理后面”两种操作。

| 变量 | 含义 |
| --- | --- |
| max_s1 / min_s1 | 前 n − 1 个字符中的最大值 / 最小值 |
| max_s2 / min_s2 | 后 n − 1 个字符中的最大值 / 最小值 |
| ifs1sort | 前缀是否已经非递减 |
| ifs2sort | 后缀是否已经非递减 |

注意，s2 的最后一个位置是 n − 2，所以代码里的 `s2[s.length() - 2]` 正好就是原字符串的最后一个字符。

## 答案为 0：整个字符串已有序

当 n 至少为 3 时，s1 和 s2 覆盖了原字符串中的所有相邻字符对。两者都非递减，就说明原字符串也非递减：

```cpp
if (ifs1sort && ifs2sort) {
    return 0;
}
```

这一步要先判断。已有序的字符串同样满足后面的部分极值条件，但它根本不需要操作，不能误算为 1。

## 答案为 1：首字符最小，或尾字符最大

如果首字符不大于后缀中的最小字符，首字符已经处于全局最小的位置。只需排序剩余后缀，就能让整体有序。

对称地，如果尾字符不小于前缀中的最大字符，只需排序前缀即可。

这正是代码中的条件：

```cpp
s1[0] <= min_s2 || s2[s.length() - 2] >= max_s1
```

例如 bac 的尾字符 c 已经最大，排序前缀 ba，就得到 abc。

这个条件也解释了为什么其他情况做不到一步：一次合法操作无法同时包含首尾，至少会留下一个端点不变。若留下首字符，它必须是全局最小；若留下尾字符，它必须是全局最大，才能得到有序结果。

## 答案为 3：唯一最大在头，唯一最小在尾

代码接着判断：

```cpp
s1[0] > max_s2 && s2[s.length() - 2] < min_s1
```

第一个严格不等式表示首字符比其余所有字符都大，即唯一最大字符位于开头。第二个表示尾字符比其余所有字符都小，即唯一最小字符位于结尾。

为什么两步不够？第一次操作不能同时包含首尾，所以至少有一个错误的端点保持不动。如果留下开头的唯一最大字符，最后一次操作就必须把它从第一位搬到最后一位，这需要覆盖整个字符串，题目不允许；留下结尾的唯一最小字符同理。

三步则一定可以做到。以 cba 为例，依次排序前缀、后缀、前缀：

```text
cba
→ bca：排序前两个字符
→ bac：排序后两个字符
→ abc：排序前两个字符
```

对一般长度，这三个操作都选择 n − 1 个字符。第一次将唯一最大字符送到前缀末端；第二次把最大字符送到全串末尾，并将最小字符移入前缀；第三次排序前缀后，整体有序。因此这类情况恰好需要 3 次。

## 其余情况为什么恰好是 2

执行到最后的 else 时，字符串既没有序，也不能一步完成，又不属于上述唯一极值卡在两端的情况。

此时至少满足下面一个条件：

- 前 n − 1 个字符中含有某个全局最小字符。先排序前缀，让最小字符到达首位，再排序后缀，即可完成。
- 后 n − 1 个字符中含有某个全局最大字符。先排序后缀，让最大字符到达末位，再排序前缀，即可完成。

例如 bca 可以先排序后缀 ca 得到 bac，再排序前缀 ba 得到 abc，正好两步。

由于前面的判断已经排除了 0 和 1 次，两步构造又确实存在，所以这里返回 2。

## 严格不等号不能随意改动

三次操作的判断强调极值唯一。如果首字符只是并列最大，后缀中仍有最大字符，可以先把它送到末尾；如果尾字符是并列最小，前缀中也可能直接找到最小字符。

例如 ccba 虽然首字符最大、尾字符最小，却只需要两次：

```text
ccba → cabc → abcc
```

所以三次操作的条件使用严格的大于和小于，不能换成大于等于、小于等于。

## 几个分支放在一起看

| 字符串 | 最少次数 | 原因 |
| --- | ---: | --- |
| aab | 0 | 已经非递减 |
| bac | 1 | 尾字符为全局最大，排序前缀即可 |
| bca | 2 | 后缀排序后固定最大字符，再排序前缀 |
| cba | 3 | 唯一最大在首位，唯一最小在末位 |
| ccba | 2 | 最大字符不唯一，不满足三次操作条件 |
| ba | -1 | 长度为 2，合法操作无法改变顺序 |

## C++ 实现

下面保留原代码：

```cpp
class Solution {
public:
    int minOperations(string s) {
        if (s.length() == 2) {
            if (s[0] <= s[1]) {
                return 0;
            }
            else {
                return -1;
            }
        }
        else if (s.length() == 1) {
            return 0;
        }
        else {
                string s1 = s.substr(0, s.length() - 1);
                string s2 = s.substr(1, s.length() - 1);
                char max_s1, min_s1, max_s2, min_s2;
                max_s1 = s1[0];
                min_s1 = s1[0];
                max_s2 = s2[0];
                min_s2 = s2[0];
                bool ifs1sort = true;
                bool ifs2sort = true;
                for (int i = 1; i < s.length() - 1; i++) {
                    if (max_s1 < s1[i]) {
                        max_s1 = s1[i];
                    }
                    if (min_s1 > s1[i]) {
                        min_s1 = s1[i];
                    }
                    if (max_s2 < s2[i]) {
                        max_s2 = s2[i];
                    }
                    if (min_s2 > s2[i]) {
                        min_s2 = s2[i];
                    }
                    if (s1[i] < s1[i - 1]) {
                        ifs1sort = false;
                    }
                    if (s2[i] < s2[i - 1]) {
                        ifs2sort = false;
                    }
                }
                if (ifs1sort && ifs2sort) {
                    return 0;
                }
                else if (s1[0] <= min_s2 || s2[s.length() - 2] >= max_s1) {
                    return 1;
                }
                else if (s1[0] > max_s2 && s2[s.length() - 2] < min_s1) {
                    return 3;
                }
                else {
                    return 2;
                }
        }
        return 0;
    }
};
```

## 复杂度分析

- 时间复杂度为 O(n)：创建两个子串和同时扫描前后缀都只需要线性时间，代码没有实际调用排序。
- 辅助空间复杂度为 O(n)：s1 和 s2 都会复制字符。虽然极值与状态变量只占常数空间，但这份实现不能按 O(1) 空间计算。

这道题的切入点是“不能一次处理整个字符串”。先看首尾有哪些字符必须保留，再看能否用前后缀操作固定一个正确的端点，就能把看似需要模拟的问题化成少量分类判断。
