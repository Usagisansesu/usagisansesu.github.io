---
title: 今日の一問 · 3963. 経路がちょうど一つのグリッドを構成する
summary: 障害物で埋めてから最上行と最右列を開き、右へ進んでから下へ向かう唯一の経路を作る。
---

m × n のグリッドを構成する問題。点は空きマス、シャープは障害物を表す。左上から右または下にだけ移動して右下に到達し、有効な経路をちょうど一つにする。

私は全体を障害物で埋めてから、最上行と最右列に折れ曲がる経路を開く方法を使った。始点と終点の接続を保証しつつ、余分な経路を作らずに済む。

## 考え方：通れる道を一つだけ残す

これは構成問題であり、複雑なグリッドを先に作って経路数を数える必要はない。条件を満たす任意の答えでよいので、分岐しない配置を直接設計する。

選んだ経路は次のとおり。

```text
(0, 0)
    → 最上行を右へ進む
(0, n - 1)
    → 最右列を下へ進む
(m - 1, n - 1)
```

この経路以外をすべて障害物にする。

## コードによる構成

m 行・各 n 文字の結果を作り、全位置をシャープで初期化する。

```cpp
vector<string> answer(m, string(n, '#'));
```

最初のループは行添字を走査し、各行の最後の文字を点に変えて最右列を開く。

```cpp
for (int i = 0; i < m; i++) {
    answer[i][n - 1] = '.';
}
```

二つ目は列添字を走査し、最上行をすべて点にする。

```cpp
for (int i = 0; i < n; i++) {
    answer[0][i] = '.';
}
```

構成時に最右列、最上行の順で変更しても、最終的に歩く順番とは無関係である。右上は二度代入されるが、どちらも点なので問題ない。

## 例で確認する

m = 4、n = 5 なら次の配置になる。

```text
.....
####.
####.
####.
```

左上から最右列までは下が障害物なので右にしか進めない。右上に来ると右は範囲外となり、最右列を下って終点へ向かう。

経路は m + n - 1 個の空きマスを通り、移動は m + n - 2 回となる。右上は最上行と最右列の両方に属するが、マス数では一度だけ数える。

## C++ 実装

以下は元のコードをそのまま掲載する。

```cpp
class Solution {
public:
    vector<string> createGrid(int m, int n) {
        vector<string> answer(m, string(n, '#'));
        for (int i = 0; i < m; i++) {
            answer[i][n - 1] = '.';
        }
        for (int i = 0; i < n; i++) {
            answer[0][i] = '.';
        }
        return answer;
    }
};
```

## 経路がちょうど一つになる理由

まず存在を確認する。最上行と最右列が空きマスで右上で交わるので、右に進んでから下に進めば始点から終点へ到達できる。

次に二本目がないことを考える。最上行で最右列に到達する前は、下がグリッド内であれば障害物なので早く下へ曲がれない。最右列では右へ進めず下へ行くしかない。各段階で合法な進行方向が一意なため、ほかの有効経路は存在しない。

存在と一意性から、要求を満たす構成である。

## 一行・一列も同じコードで扱える

- m = 1：最上行だけなので、右へ進む唯一の経路となる。
- n = 1：最右列だけなので、下へ進む唯一の経路となる。
- m = 1 かつ n = 1：一つの点が始点かつ終点で、移動せずにちょうど一つの経路がある。

いずれも元のコードで自然に扱え、追加分岐はいらない。

## 計算量

- 時間計算量は O(m × n)。結果の初期化に m × n 文字の書き込みが必要で、その後 m + n 回代入する。二つのループだけを見て O(m + n) としてはいけない。
- 空間計算量は O(m × n)。返却グリッドがその領域を使う。返却結果以外はループ変数だけで、補助空間は O(1)。

鍵は「条件に合う任意のグリッド」でよいことだ。分岐をすべて閉じれば、動的計画法で経路数を数えずに一意性を保証できる。
