一回の操作で連続部分文字列をソートできるが、文字列全体は選べない。私のコードは実際にソートせず、接頭辞・接尾辞の最小・最大文字と整列状態を調べ、両端の条件から最小回数を決める。

## 長さ 1 と 2 を先に扱う

長さ 1 は元から整列しているので 0 を返す。

長さ 2 では合法な非空真部分文字列は一文字だけで、ソートしても変化しない。最初から整列していれば 0、そうでなければ -1 となる。

長さが 3 以上なら、前 n − 1 文字と後 n − 1 文字は合法な操作区間なので、以後はそれを使って分類する。

## s1 と s2 を調べる理由

長さ n − 1 の文字列を二つ作る。

```text
s1 = s[0 .. n-2]：最後の文字を除いた接頭辞
s2 = s[1 .. n-1]：最初の文字を除いた接尾辞
```

それぞれ「末尾を固定して前を整える」「先頭を固定して後ろを整える」操作に対応する。

| 変数 | 意味 |
| --- | --- |
| max_s1 / min_s1 | 前 n − 1 文字の最大値 / 最小値 |
| max_s2 / min_s2 | 後 n − 1 文字の最大値 / 最小値 |
| ifs1sort | 接頭辞が非減少か |
| ifs2sort | 接尾辞が非減少か |

s2 の最後の添字は n − 2 なので、`s2[s.length() - 2]` は元の文字列の末尾を表す。

## 0 回：全体が既に整列している

n が 3 以上なら、s1 と s2 で元の全隣接対を覆う。両方が非減少なら元の文字列も非減少である。

```cpp
if (ifs1sort && ifs2sort) {
    return 0;
}
```

この判定を最初に行う。整列済みでも後の極値条件を満たすことがあるが、操作は不要なので 1 と誤判定してはいけない。

## 1 回：先頭が最小、または末尾が最大

先頭が接尾辞の最小文字以下なら、既に大域最小の位置にいるため、残りの接尾辞をソートすればよい。

対称的に、末尾が接頭辞の最大文字以上なら、接頭辞をソートするだけで完成する。

これが次の条件である。

```cpp
s1[0] <= min_s2 || s2[s.length() - 2] >= max_s1
```

例えば bac は末尾の c が最大なので、前の ba をソートすれば abc となる。

ほかの場合に一回でできない理由も分かる。合法な一操作は両端を同時には含めず、少なくとも片端を残す。先頭を残すなら大域最小、末尾を残すなら大域最大でなければ整列結果にならない。

## 3 回：唯一の最大が先頭、唯一の最小が末尾

次にコードはこれを判定する。

```cpp
s1[0] > max_s2 && s2[s.length() - 2] < min_s1
```

最初の厳密不等式は先頭がほかのすべてより大きいこと、二つ目は末尾がほかのすべてより小さいことを表す。

なぜ二回では足りないのか。最初の操作は両端を含めないので、誤った端点が一つは残る。先頭の唯一の最大を残すと、最後の操作で先頭から末尾へ移すには全体を含めなければならず、禁止されている。末尾の唯一の最小を残す場合も同じだ。

三回なら必ず可能。cba で接頭辞、接尾辞、接頭辞を順にソートする。

```text
cba
→ bca：最初の二文字をソート
→ bac：最後の二文字をソート
→ abc：最初の二文字をソート
```

一般にも各操作で n − 1 文字を選ぶ。最初に最大を接頭辞末尾へ、次に全体の末尾へ移しつつ最小を接頭辞に入れ、最後に接頭辞をソートする。よってこの場合はちょうど 3 回となる。

## 残りがちょうど 2 回になる理由

最後の else では、整列済みでも一回で可能でもなく、上記の唯一の極値が両端にある場合でもない。

少なくとも次のどちらかが成り立つ。

- 前 n − 1 文字に大域最小がある。接頭辞をソートして最小を先頭へ置き、接尾辞をソートすれば完成する。
- 後 n − 1 文字に大域最大がある。接尾辞をソートして最大を末尾へ置き、接頭辞をソートすれば完成する。

bca なら後ろの ca をソートして bac、前の ba をソートして abc と二回でできる。

0 回と 1 回は既に除外し、二回の構成が存在するので 2 を返す。

## 厳密な不等号を変えてはいけない

三回の条件には極値の一意性が重要だ。先頭と同じ最大が接尾辞にもあれば末尾に送れるし、末尾と同じ最小が接頭辞にあれば先頭に置ける。

例えば ccba は先頭が最大・末尾が最小でも二回で済む。

```text
ccba → cabc → abcc
```

したがって三回の条件の大なり・小なりを、以上・以下へ変えてはいけない。

## 分岐をまとめる

| 文字列 | 最小回数 | 理由 |
| --- | ---: | --- |
| aab | 0 | 既に非減少 |
| bac | 1 | 末尾が大域最大なので接頭辞をソート |
| bca | 2 | 接尾辞で最大を末尾へ固定し、接頭辞をソート |
| cba | 3 | 唯一の最大が先頭、唯一の最小が末尾 |
| ccba | 2 | 最大が一意でなく、三回の条件を満たさない |
| ba | -1 | 長さ 2 では合法操作で順序を変えられない |

## C++ 実装

以下は元のコード。

```cpp
class Solution {
public:
    int minOperations(string s) {
        if (s.length() == 2) {
            if (s[0] <= s[1]) {
                return 0;
            }
            else {
                return -1;
            }
        }
        else if (s.length() == 1) {
            return 0;
        }
        else {
                string s1 = s.substr(0, s.length() - 1);
                string s2 = s.substr(1, s.length() - 1);
                char max_s1, min_s1, max_s2, min_s2;
                max_s1 = s1[0];
                min_s1 = s1[0];
                max_s2 = s2[0];
                min_s2 = s2[0];
                bool ifs1sort = true;
                bool ifs2sort = true;
                for (int i = 1; i < s.length() - 1; i++) {
                    if (max_s1 < s1[i]) {
                        max_s1 = s1[i];
                    }
                    if (min_s1 > s1[i]) {
                        min_s1 = s1[i];
                    }
                    if (max_s2 < s2[i]) {
                        max_s2 = s2[i];
                    }
                    if (min_s2 > s2[i]) {
                        min_s2 = s2[i];
                    }
                    if (s1[i] < s1[i - 1]) {
                        ifs1sort = false;
                    }
                    if (s2[i] < s2[i - 1]) {
                        ifs2sort = false;
                    }
                }
                if (ifs1sort && ifs2sort) {
                    return 0;
                }
                else if (s1[0] <= min_s2 || s2[s.length() - 2] >= max_s1) {
                    return 1;
                }
                else if (s1[0] > max_s2 && s2[s.length() - 2] < min_s1) {
                    return 3;
                }
                else {
                    return 2;
                }
        }
        return 0;
    }
};
```

## 計算量

- 時間は O(n)。二つの部分文字列の生成と走査は線形で、実際のソートはしない。
- 補助空間は O(n)。s1 と s2 に文字をコピーする。極値と状態変数が定数空間でも、この実装全体を O(1) とはできない。

着眼点は「一回で全体を処理できない」こと。両端のどの文字を残す必要があるか、接頭辞・接尾辞で正しい端点を固定できるかを考えると、シミュレーションに見える問題を少数の場合分けに変えられる。
